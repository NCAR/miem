
Citing MIEM
===========

MIEM is a group scientific and software effort, developed as part of the
`MUSICA <https://github.com/NCAR/musica>`_ framework.

Cite the science
----------------

If you use MIEM in published work, please cite the MUSICA framework
:cite:`Pfister2020`.

Cite the software
-----------------

A versioned software citation with a DOI will be minted on the first release.
Until then, please reference the repository directly:

.. code-block:: console

  @software{ncar.acom.miem,
    author    = {{NSF NCAR/ACOM}},
    title     = {NCAR/miem: Model Independent Emissions Module},
    publisher = {GitHub},
    url       = {https://github.com/NCAR/miem}
  }
